Osebni projekt | Nejc Sever Mihelič

Pregled delovanja aplikacije

Projekt predstavlja sodobno spletno aplikacijo za preglede, upravljanje in ocenjevanje filmskih zbirke, razvito z ogrodjem ASP.NET Core MVC. Glavni cilj sistema je uporabnikom omogočiti enostavno raziskovanje filmov, filtriranje po žanrih, upravljanje osebnega seznama priljubljenih filmov ter natančen pregled podrobnosti posameznega naslova.

Podatkovna struktura temelji na zanesljivi bazi SQL Server (preko Entity Framework Core), kar omogoča hitro preiskovanje podatkov, varno shranjevanje informacij o filmih ter upravljanje ocen in komentarjev uporabnikov.

Katalog & Iskanje

Pregleden izpis baze filmov z možnostjo hitrega iskanja po naslovu, režiserju ali žanru.

CRUD Upravljanje

Celovito dodajanje, urejanje, pregledovanje in brisanje podatkov o filmih (naslov, datum izida, žanr, ocena, opis).

Filtriranje po Žanrih

Napredno filtriranje vsebin za hiter dostop do želenih filmskih kategorij in vrst produkcije.

Ocenjevanje & Opisi

Sistem za dodajanje uporabniških ocen ter podrobnih opisov in informacij o posameznem filmu.

Varnost & Identity

Integracija ASP.NET Identity za avtentikacijo uporabnikov in omejevanje pravic urejanja podatkov.

Odziven UI

Sodoben in prilagodljiv uporabniški vmesnik, optimiziran za namizne računalnike, tablice in mobilne naprave.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih tehnologij za spletni razvoj:

  • Visual Studio 2022 za razvoj in upravljanje projekta.
  • ASP.NET Core MVC za arhitekturo in strežniško logiko.
  • Entity Framework Core za interakcijo s podatkovno bazo (ORM).
  • SQL Server / LocalDB za shranjevanje podatkov o filmih in uporabnikih.
  • HTML5, CSS3 & Bootstrap za odziven in privlačen uporabniški vmesnik.
  • GitHub za verzioniranje kode.
