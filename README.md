# Portfolio & Resume Website / Osebni Portfolio

A modern, responsive, and interactive personal portfolio website built with HTML5, CSS3 (Custom Properties), and Vanilla JavaScript. Designed to showcase education, skills, interactive project cards, and contact information with light/dark theme support. Fully available in **Slovenian** and **English**.

Sodobna, odzivna in interaktivna osebna spletna stran (portfolio), izdelana s tehnologijami HTML5, CSS3 in Vanilla JavaScript. Namenjena je predstavitvi izobrazbe, veščin, projektov ter kontaktnih podatkov z podporo za svetlo in temno temo. Vsebina je na voljo v **slovenščini** in **angleščini**.

---

## Features / Lastnosti

- **Multilingual Content / Večjezična vsebina**: Interface and project descriptions in both Slovenian and English (Podpora za slovenski in angleški jezik).
- **Responsive Layout**: Optimized for desktop, tablet, and mobile viewing with a clean card-based design.
- **Dark Mode / Light Mode**: Dynamic theme switching using CSS custom variables and persistent styling toggle.
- **Interactive Project Showcase**:
  - Displays featured projects with direct links to live pages and source code.
  - Expandable grid that defaults to displaying 4 top projects with a **"Display more projects"** toggle button.
- **Collapsible Sections**: Smooth expandable "Preberi več" (Read More) sections for biographical details.
- **Clean Structure**: BEM/Utility-style CSS with zero heavy third-party framework dependencies.

---

## Languages & Tech Stack / Jeziki in Tehnologije

### Languages / Jeziki
- **Slovenian / Slovenščina** (Primary UI & Content)
- **English / Angleščina** (Technical descriptions & Repository documentation)

### Tech Stack / Tehnologije
- **HTML5**: Semantic markup for accessibility and structure.
- **CSS3**: CSS Variables (`:root`), Flexbox, CSS Grid, and custom transitions.
- **JavaScript (ES6+)**: DOM manipulation for dark mode toggle, expandable project grid, and collapsible text content.
