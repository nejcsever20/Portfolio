Aplikacija TodoList React

Osebni projekt | Nejc Sever Mihelič

Pregled delovanja aplikacije

Projekt predstavlja dinamično in interaktivno jedrno spletno aplikacijo za upravljanje opravil in dnevnih obveznosti, razvito z knjižnico React.js. Glavni cilj sistema je uporabniku zagotoviti bliskovito hitro uporabniško izkušnjo brez osveževanja strani (SPA - Single Page Application) z intuitivnim upravljanjem stanja aplikacije (state management).

Sistem omogoča sprotno dodajanje, označevanje opravljenih nalog, urejanje ter filtriranje obveznosti. Shranjevanje podatkov je lahko lokalno (LocalStorage) ali preko integracije z zunanjim API-jem za varno in trajno hranjenje stanja.

Upravljanje Opravil (CRUD)

Enostavno ustvarjanje novih nalog, spreminjanje besedila, označevanje dokončanih opravil ter brisanje.

Filtriranje po Stanju

Hiter pregled nalog glede na status: vsa opravila, aktivna/nedokončana ter zaključena opravila.

Komponentna Arhitektura

Zasnova z večkrat uporabnimi React komponentami (TaskInput, TaskItem, TaskList, FilterButtons) za čisto kodo.

Reaktivno Stanje (React Hooks)

Uporaba modernih React konceptov (useState, useEffect) za dinamično posodabljanje uporabniškega vmesnika v realnem času.

Lokalno Shranjevanje

Integracija z LocalStorage za ohranjanje vnosa nalog tudi ob osvežitvi ali ponovnem obisku strani.

Sodoben & Odziven UI

Čist in minimalističen dizajnerski pristop z nemoteno uporabo na mobilnih napravah in namiznih računalnikih.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih orodij za front-end spletni razvoj:

  • React.js za gradnjo interaktivnega uporabniškega vmesnika (UI).
  • JavaScript (ES6+) za sodobno logiko in manipulacijo podatkov.
  • HTML5 & CSS3 za strukturo, stilsko oblikovanje in odzivnost.
  • Node.js & npm za upravljanje paketov in razvojno okolje.
  • Visual Studio Code za razvoj in pisanje kode.
  • GitHub za verzioniranje in gostovanje projekta.
