Pregled delovanja aplikacije

Projekt predstavlja sodobno interaktivno spletno mesto za predstavitev osebnih projektov, tehničnih znanj, razvijalskih izkušenj in življenjepisa. Stran je zasnovana z poudarkom na estetiki, preglednosti in hitrem dostopu do ključnih informacij o razvitih aplikacijah ter uporabljenih tehnologijah.

Spletno mesto vključuje integracijo povezav do izvornih kod (GitHub), podrobne opise posameznih projektov, kontaktni obrazec ter dinamične elemente za optimalno predstavitveno izkušnjo na vseh napravah.

Predstavitev Projektov

Pregledna galerija in kartice z opisi razvitih aplikacij, uporabljeni tehnološki sklad ter povezave do GitHub skladišč.

Pregled Znanj & Tehnologij

Strukturiran prikaz tehničnih kompetenc (C#, ASP.NET Core, SQL Server, HTML/CSS, JavaScript) in orodij.

Digitalni Življenjepis (CV)

Integriran prikaz izobraževanja, delovnih izkušenj, diplomskega dela in pridobljenih certifikatov.

Kontaktni Obrazec

Funkcionalnost za enostaven kontakt z obiskovalci in potencialnimi delodajalci ali partnerji.

Odziven & Moderen UI

Sodobni vizualni gradniki, gladki pre prehodi in prilagodljiv dizajn za brezhibno delovanje na telefonih in računalnikih.

Hitrost & Optimizacija

Optimizirana koda za hitro nalaganje, odlično uporabniško izkušnjo (UX) in visoko odzivnost stranis.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih spletnih tehnologij:

  • HTML5 & CSS3 za strukturo, moderno obliko in odzivne mreže (Flexbox & Grid).
  • JavaScript za dinamične interakcije in uporabniške učinke.
  • ASP.NET Core / Modern Web Framework za postavitev in strežniško podporo.
  • Bootstrap / Custom CSS za elegantno tipografijo in komponente.
  • GitHub & GitHub Pages / Hosting za verzioniranje in gostovanje spletne strani.
