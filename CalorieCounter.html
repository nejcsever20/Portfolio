Aplikacija Calorie Counter

Osebni projekt | Nejc Sever Mihelič

Pregled delovanja aplikacije

Projekt predstavlja sodobno spletno aplikacijo za spremljanje dnevnega vnosa kalorij in makrohranil (beljakovine, ogljikovi hidrati, maščobe), razvito z ogrodjem ASP.NET Core MVC. Glavni cilj sistema je uporabnikom omogočiti enostavno načrtovanje prehrane, bilanco kalorij ter doseganje osebnih fitnes ciljev (izguba teže, vzdrževanje ali pridobivanje mase).

Sistem vključuje varno avtentikacijo uporabnikov, vodenje baze živil ter natančen pregled dnevnega napredka s pomočjo interaktivnih grafičnih prikazov. Podatkovna struktura temelji na zanesljivi SQL bazi preko Entity Framework Core, kar omogoča hitro preračunavanje hranilnih vrednosti in varno shranjevanje podatkov.

Vodenje Dnevnika Prehrane

Enostaven vnos obrokov po kategorijah (zajtrk, kosilo, večerja, prigrizki) ter samodejni izračun skupnih kalorij.

Sledenje Makrohranilom

Natančen pregled vnosa beljakovin, ogljikovih hidratov in maščob z vizualnimi indikatorji dnevnih ciljev.

Baza Živil & Iskanje

Pregledna baza živil z možnostjo dodajanja lastnih sestavin in prilagojenih velikosti porcij.

Uporabniški Profil & Cilji

Izračun priporočenega dnevnega vnosa kalorij (BMR/TDEE) glede na starost, težo, višino in raven telesne aktivnosti.

Varnost & Identity

Uporaba ASP.NET Identity za varno registracijo, prijavo in zaščito osebnih podatkov uporabnika.

Odziven Dizajn

Prilagojen uporabniški vmesnik za nemoteno uporabo na mobilnih telefonih, tablicah in namiznih računalnikih.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih tehnologij za spletni razvoj:

  • Visual Studio 2022 za razvoj in upravljanje projekta.
  • ASP.NET Core MVC za robustno backend logiko in arhitekturo.
  • Entity Framework Core za delo s podatkovno bazo (ORM).
  • SQL Server / LocalDB za shranjevanje podatkov o živilih in dnevnikih.
  • HTML5 & CSS3 / Bootstrap za moderen, odziven in pregleden uporabniški vmesnik.
  • GitHub za verzioniranje kode.
