Pregled delovanja aplikacije

Projekt predstavlja celovito spletno aplikacijo za upravljanje izobraževalne ustanove (študenti, profesorji, predmeti in vpisi), razvito z ogrodjem ASP.NET Core MVC in Entity Framework Core. Glavni cilj sistema je prikaz kompleksnih podatkovnih relacij (1:N in M:N), upravljanje vpisnih rokov ter spremljanje akademskega napredka.

Sistem vključuje napredno obdelavo podatkov, razvrščanje (sorting), filtriranje, strančenje (paging) ter zanesljivo upravljanje transakcij v SQL Server podatkovni bazi za zagotavljanje konsistentnosti podatkov.

Upravljanje Študentov & Profesorjev

Celovit pregled, dodajanje, urejanje in brisanje podatkov o študentih, predavateljih in njihovi pripadnosti oddelkom.

Katalog Predmetov & Vpisi

Dodeljevanje predmetov profesorjem, vpisovanje študentov na predmete ter vodenje ocen in kreditnih točk (KT/ECTS).

Filtriranje, Iskanje & Paging

Optimiziran prikaz velikih količin podatkov z možnostjo hitrega iskanja po priimku ali imenu ter strančenja rezultaov.

Kompleksne Relacije (EF Core)

Uporaba naprednih Entity Framework koncepte, kot so explicit/eager loading, obdelava konfliktov sočasnosti (concurrency) in migracije.

Statistika & Poročila

Agregirani pregledi števila vpisanih študentov po datumih ter statistika uspešnosti po posameznih predmetih.

Odziven UI

Sodoben uporabniški vmesnik z uporabo CSS Flexbox/Grid in Bootstrap komponent za prilagodljivost na vseh ekranih.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih tehnologij za spletni razvoj in upravljanje podatkov:

  • Visual Studio 2022 za razvoj in arhitekturo rešitve.
  • ASP.NET Core MVC za grajenje strežniške logike in uporabniških pogledov.
  • Entity Framework Core za objektno-relacijsko preslikovanje (ORM).
  • SQL Server / LocalDB za shranjevanje relacijskih podatkov.
  • HTML5, CSS3 & Bootstrap 5 za odziven in pregleden uporabniški vmesnik.
  • GitHub za verzioniranje kode.
