Aplikacija ApiProject (Web API)

Osebni projekt | Nejc Sever Mihelič

Pregled delovanja aplikacije

Projekt predstavlja napreden backend Web API, razvit z ogrodjem ASP.NET Core Web API. Glavni cilj rešitve je zagotavljanje varne, zmogljive in skalabilne RESTful storitve za izmenjavo podatkov med podatkovno bazo ter zunanjimi odjemalci (spletne aplikacije, mobilne naprave ali zunanji integracijski sistemi).

Arhitektura API-ja temelji na ločenih slojih (Controller/Service/Repository vzorec) ter uporabi Entity Framework Core za delo s SQL Server bazo. Za enostavno testiranje in dokumentiranje končnih točk (endpoints) je vključena interaktivna dokumentacija Swagger (OpenAPI).

RESTful Končne Točke

Standardizirane HTTP metode (GET, POST, PUT, DELETE) za celovito upravljanje virov ter ustrezne kode odgovorov.

Swagger / OpenAPI

Integriran Swagger UI za sprotno testiranje API zahtev ter pregledno dokumentacijo vseh vhodnih in izhodnih modelov.

Avtentikacija & JWT Žetoni

Varna avtorizacija dostopa do končnih točk z uporabo JSON Web Token (JWT) standarda in avtentikacije uporabnikov.

Validacija Podatkov & DTO

Uporaba DTO (Data Transfer Object) vzorca in validacije vhodnih podatkov za preprečevanje neveljavnih vnosov.

Entity Framework Core

Učinkovita komunikacija s podatkovno bazo, asinhrono izvajanje poizvedb (async/await) ter upravljanje migracij.

Centralizirano Lovljenje Napak

Enotno obvladovanje izjem (global error handling middleware) z ustreznim formatiranjem napak za odjemalca.

Tehnologije in Orodja

Projekt je razvit z uporabo sodobnih backend tehnologij in orodij:

  • Visual Studio 2022 za razvoj backend arhitekture.
  • ASP.NET Core Web API za izdelek RESTful storitev.
  • Entity Framework Core za objektno-relacijsko preslikovanje (ORM).
  • Swagger / OpenAPI za interaktivno dokumentacijo API-ja.
  • SQL Server / LocalDB za shranjevanje podatkov.
  • Postman / Swagger UI za testiranje in preverjanje končnih točk.
